# Práctica 03 - Tecnología de Objetos

Práctica de clase del curso de Tecnología de Objetos. Trata sobre clases abstractas y polimorfismo en C++.

## Ejercicios

- `ejercicio01_empleados.cpp`: sistema de empleados con la clase abstracta `Empleado` y tres tipos de empleado que calculan su salario de forma distinta.
- `ejercicio02_vehiculos.cpp`: sistema de vehículos con la clase abstracta `Vehiculo`. Automóvil, motocicleta y camión aceleran y frenan cada uno a su manera.

## Cómo ejecutar

```bash
g++ -std=c++17 -o ej1 ejercicio01_empleados.cpp
./ej1

g++ -std=c++17 -o ej2 ejercicio02_vehiculos.cpp
./ej2
```
